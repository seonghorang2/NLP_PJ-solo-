# 사용자 노출용 카테고리 초안 v2

## 1) 목적
- 이 문서는 분석용 라벨을 그대로 노출하지 않고, 구매 판단에 바로 쓰이는 사용자 언어로 재해석한 노출 규칙을 정의한다.
- 분석 파이프라인은 유지하고, 제목/요약/근거 표현만 사용자 중심으로 변환한다.

## 2) v2 적용 범위
- 코호트: `cohort_v1` (16개, `1085660 Destiny 2` 포함)
- 데이터 근거: `cohort_v1_category_aggregate_snapshot_v2.json`
- 보강 루프 반영: `cohort_v1_rule_reinforcement_loop_summary.json`

## 3) 사용자 노출 축(6개)

| 노출 축 | 내부 매핑 키 |
|---|---|
| 핵심 재미 체감 | `gameplay`, `story`, `graphics`, `customization` |
| 입문/적응 부담 | `difficulty`, `controls` |
| 기술 안정성 | `performance`, `bugs`, `save_progression` |
| 장기 플레이 가치 | `content_depth`, `building_ux`, `mod_support` |
| 멀티/공정성 신뢰 | `multiplayer`, `balance` |
| 가격 대비 가치 | `monetization`, `localization` |

## 4) 금지 라벨 (직접 제목 노출 금지)
- `DLC / 확장팩 언급`
- `건축 조작 불편`
- `~ 문제`, `~ 이슈`, `~ 불만`, `~ 언급` 형태의 내부 진단 라벨 전반

## 5) v2 제목 치환 문장 가이드

| 내부 라벨 | 사용자 노출 제목(치환) |
|---|---|
| 최적화 문제 | 전투·이동 중 프레임 저하로 몰입이 끊긴다는 반응 |
| 일반 버그 | 예상치 못한 오류가 반복돼 플레이 리듬이 깨진다는 반응 |
| 매칭 / 서버 문제 | 매칭 대기와 서버 불안정으로 플레이 템포가 끊긴다는 반응 |
| 조작 / 규칙 학습 난이도 | 초반 학습 부담은 있지만 익숙해지면 손맛이 살아난다는 반응 |
| 가격 / 과금 불만 | 가격 대비 체감 만족이 기대보다 낮다는 반응 |
| DLC / 확장팩 언급 | 추가 콘텐츠 가치가 기대에 못 미쳐 구매가 망설여진다는 반응 |
| 건축 조작 불편 | 배치/건설 편의성이 낮아 창작 흐름이 자주 끊긴다는 반응 |

## 6) 노출 블록 구성 규칙
- 강점: 2~3개
- 리스크: 2~3개
- 각 블록 근거 스니펫: 2~3개
- 규칙:
  - 제목/근거 stance 일치 필수
  - 고합의(고빈도) 우선
  - 저빈도 단건 의견은 보조로만 사용

## 7) v2 집계에서 우선 노출해야 할 사용자 포인트
- 기술 안정성: 최적화/버그 관련 언급이 지속 상위
- 입문/적응: 난이도/학습 부담 언급 빈도 높음
- 멀티/공정성: 매칭/보안/밸런스 신호가 반복됨
- 장기 가치: 반복·콘텐츠 밀도 관련 불만/호평 공존
- 가격 가치: 과금/확장팩 가치 판단 신호가 꾸준함

## 8) A/B 점검 기준 (v2)
- 금지 라벨 노출률: 0%
- 제목-근거 정합성: 90% 이상
- 이해 즉시성(3초 판단): 평균 4/5 이상
- 과도한 분석어(내부 라벨) 포함률: 10% 미만
