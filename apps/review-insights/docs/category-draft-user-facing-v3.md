# 사용자 노출용 카테고리 초안 v3 (구매 판단 리포트)

## 1) 목적
- 본 문서는 분류 결과를 **실사용자 구매 판단 문장**으로 변환하는 노출 규칙을 고정한다.
- 리포트 목표는 분석 설명이 아니라:
  - 지금 사도 되는지
  - 나에게 맞는 게임인지
  - 감수할 리스크가 무엇인지
  를 빠르게 판단하게 하는 것이다.

## 2) 노출 원칙 (v3)
- 카테고리 키(`gameplay`, `monetization` 등)를 그대로 제목으로 노출하지 않는다.
- 증거 블록은 반드시 `강점`/`리스크`를 분리한다.
- 저빈도 단일 의견보다 고합의 반복 의견을 우선 노출한다.
- 숫자/카운트 중심 문구 대신 플레이 체감 문장으로 변환한다.

## 3) 노출 금지 라벨 (v3)
- `DLC / 확장팩 언급` (제목 직접 노출 금지)
- `건축 조작` 계열 문구 (사용자 체감 문구로만 우회)
- `~ 문제`, `~ 불만`, `~ 언급` 같은 내부 분류형 제목

## 4) 사용자 노출 축 (내부 분류 매핑)

### A. 플레이 재미/핵심 경험
- 내부 매핑: `gameplay`, `story`, `graphics`, `customization`
- 노출 예시:
  - 반복할수록 손에 붙는 전투/조작 재미
  - 세계관과 연출 덕분에 몰입이 오래 유지됨

### B. 입문 난이도/학습 곡선
- 내부 매핑: `difficulty`, `controls`
- 노출 예시:
  - 초반 적응이 필요하지만 익숙해지면 보상이 큼
  - 조작 학습 난도가 높아 입문 장벽이 있음

### C. 기술 안정성
- 내부 매핑: `performance`, `bugs`, `save_progression`
- 노출 예시:
  - 프레임 저하/버그로 흐름이 끊길 수 있음
  - 장시간 플레이 시 안정성이 만족도를 좌우함

### D. 장기 플레이 가치
- 내부 매핑: `content_depth`, `mod_support`, `building_ux`
- 노출 예시:
  - 콘텐츠 소모 속도 대비 장기 동기 유지가 핵심 변수
  - 확장성(모드/커뮤니티)이 만족도를 끌어올림

### E. 멀티플레이 체감/공정성
- 내부 매핑: `multiplayer`, `balance`
- 노출 예시:
  - 매칭 품질과 팀 환경이 체감 품질을 크게 좌우함
  - 밸런스/공정성 이슈에 민감하면 피로도가 높을 수 있음

### F. 가격 대비 가치
- 내부 매핑: `monetization`, `localization`
- 노출 예시:
  - 현재 가격 메리트가 구매 만족도를 좌우함
  - 한국어 품질/지원 수준이 체감 진입장벽에 영향

## 5) 증거 블록 규칙 (필수)
- 강점 2~3 블록, 리스크 2~3 블록.
- 각 블록은 `title + why_it_matters + snippets(2~3)` 구조.
- 스니펫은 원문 의미를 유지하되 읽기 쉬운 길이로 정리한다.
- 제목/설명/스니펫의 stance 불일치 시 후보를 교체한다.

- 금지 라벨은 제목 직출 금지 후 경험형 문장으로 치환.
