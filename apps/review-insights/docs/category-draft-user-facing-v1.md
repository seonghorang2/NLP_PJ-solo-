# 사용자 노출용 카테고리 초안 v1

## 1) 목적
- 이 문서는 실사용자(구매 전 의사결정) 관점에서 리포트에 노출할 카테고리 구조를 정의한다.
- 내부 분류(`category_tags`, `canonical_theme`)는 유지하고, 사용자 화면에는 경험형 문장만 노출한다.

## 2) 노출 원칙
- 결론 중심: 제목만 보고도 구매 판단에 도움되어야 한다.
- 라벨 금지: 내부 분석 라벨 형태(`~ 이슈`, `~ 언급`, `~ 불만`)는 직접 노출하지 않는다.
- 고합의 우선: 반복 등장한 신호만 상위 블록에 노출한다.

## 3) 사용자 노출 축(6개)

| 노출 축 | 내부 카테고리 매핑 |
|---|---|
| 핵심 재미 체감 | `gameplay`, `story`, `graphics`, `customization` |
| 입문/적응 부담 | `difficulty`, `controls` |
| 기술 안정성 | `performance`, `bugs`, `save_progression` |
| 장기 플레이 가치 | `content_depth`, `building_ux`, `mod_support` |
| 멀티/공정성 신뢰 | `multiplayer`, `balance` |
| 가격 대비 가치 | `monetization`, `localization` |

## 4) 금지 라벨(직접 노출 금지) 고정
- `DLC / 확장팩 언급`은 제목으로 직접 노출하지 않는다.
- `건축 조작 불편`은 제목으로 직접 노출하지 않는다.
- 그 외 내부 라벨형 제목(`~ 문제`, `~ 이슈`, `~ 불만`, `~ 언급`)도 직접 노출을 지양한다.

## 5) 치환 규칙 (경험형 문장)

| 내부 라벨 | 사용자 노출 문장(예시) |
|---|---|
| 최적화 문제 | 전투·이동 중 프레임 저하로 몰입이 끊긴다는 반응 |
| 일반 버그 | 예상치 못한 오류가 반복돼 플레이 리듬이 깨진다는 반응 |
| 매칭 / 서버 문제 | 매칭 대기와 서버 불안정으로 플레이 템포가 끊긴다는 반응 |
| 조작 / 규칙 학습 난이도 | 초반 학습 부담은 있지만 익숙해지면 손맛이 살아난다는 반응 |
| 가격 / 과금 불만 | 가격 대비 체감 만족이 기대보다 낮다는 반응 |
| DLC / 확장팩 언급 | 추가 콘텐츠 가치가 기대에 못 미쳐 구매가 망설여진다는 반응 |
| 건축 조작 불편 | 배치/건설 편의성이 낮아 창작 흐름이 자주 끊긴다는 반응 |
| 부지 / 구조 제약 | 배치 자유도가 낮아 원하는 설계를 구현하기 어렵다는 반응 |

## 6) 제목 생성 템플릿
- 강점: `~ 덕분에 ~ 경험이 좋아진다는 반응`
- 리스크: `~ 때문에 ~ 상황에서 불편이 커진다는 반응`
- 금지: 내부 분류 키워드만 나열한 제목

## 7) 노출 운영 규칙
- 강점 2~3개, 리스크 2~3개만 노출
- 근거 스니펫 2개 미만이면 해당 블록을 상위 노출하지 않음
- stance(긍/부정) 불일치 스니펫은 교체
- 리뷰 1개는 UI에서 1개 항목으로 유지(줄바꿈만 허용)

## 8) 현재 데이터 기준 우선 반영 대상
- 상위 고빈도 신호(코호트 집계)에서 사용자 영향이 큰 항목:
  - 최적화/버그
  - 난이도/적응 부담
  - 매칭/공정성
  - 콘텐츠 반복/소진
  - 가격 대비 만족

## 9) A/B 점검 기준 (1245620, 578080 우선)
- 금지 라벨 노출률: 0%
- 제목-근거 정합성: 90% 이상
- 3초 내 이해 가능성(수동 평가): 평균 4점/5점 이상
- 최종 채택: 기존 대비 평균 +1.0점 이상 개선 시 적용
