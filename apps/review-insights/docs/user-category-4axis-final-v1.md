# 실사용자 기준 카테고리 재설계 고정안 v1 (32코호트)

## 1. 목적
- 내부 분류 카테고리(16개)는 유지한다.
- 사용자 노출은 구매 판단 중심 4축으로 고정한다.
- 리포트는 분석 대시보드가 아니라 **구매 의사결정 문서**로 본다.

## 2. 4축 고정 정의
- 축 1 `나에게 맞는가`: 플레이 스타일/적합성
- 축 2 `지금 사도 되는가`: 가격/타이밍/현재 상태
- 축 3 `후회 가능성`: 성능/버그/밸런스/운영 리스크
- 축 4 `오래 할 가치`: 콘텐츠 깊이/반복 피로/확장성

## 3. 내부 카테고리 -> 사용자 4축 매핑표 (최종)

| 내부 카테고리 | 1차 축 | 보조 축 | 사용자 노출 가이드 |
|---|---|---|---|
| `gameplay` | 나에게 맞는가 | 오래 할 가치 | 전투/핵심 루프 체감 |
| `story` | 나에게 맞는가 | - | 몰입/서사 선호도 |
| `graphics` | 나에게 맞는가 | - | 시각 연출 만족도 |
| `customization` | 나에게 맞는가 | 오래 할 가치 | 빌드/꾸미기 취향 적합 |
| `difficulty` | 나에게 맞는가 | 후회 가능성 | 학습 곡선 감수 여부 |
| `controls` | 나에게 맞는가 | 후회 가능성 | 조작 적응 난도 |
| `performance` | 후회 가능성 | 지금 사도 되는가 | 프레임/끊김 리스크 |
| `bugs` | 후회 가능성 | 지금 사도 되는가 | 오류/진행 방해 리스크 |
| `save_progression` | 후회 가능성 | - | 진행 안정성 리스크 |
| `content_depth` | 오래 할 가치 | 후회 가능성 | 중후반 동기 유지 |
| `mod_support` | 오래 할 가치 | - | 확장성/수명 연장 |
| `building_ux` | 나에게 맞는가 | 오래 할 가치 | 배치/건설 조작 체감 |
| `multiplayer` | 나에게 맞는가 | 후회 가능성 | 매칭/협동/경쟁 체감 |
| `balance` | 후회 가능성 | - | 불공정 체감 리스크 |
| `monetization` | 지금 사도 되는가 | 후회 가능성 | 가격 대비 만족도 |
| `localization` | 나에게 맞는가 | 지금 사도 되는가 | 한글/현지화 진입장벽 |

## 4. 금지 라벨 치환 사전 (제목/근거 공통)
- 원칙: 내부 분류형 표현은 그대로 노출하지 않고 경험형 문장으로 치환한다.
- 원칙: `DLC / 확장팩 언급`, `건축 조작` 계열은 분류형 제목 직출 금지.

| 금지 라벨(분류형) | 치환 문장(경험형) |
|---|---|
| 조작 / 규칙 학습 난이도 | 초반 적응은 필요하지만 익숙해지면 손맛이 살아나는 플레이 구조 |
| 전투 손맛 / 액션 호평 | 전투가 반복될수록 손에 붙고 몰입이 올라가는 액션 경험 |
| 스토리 / 서사 몰입 | 세계관과 연출 덕분에 플레이를 계속하게 되는 몰입 경험 |
| 최적화 문제 | 프레임 저하나 끊김으로 전투/이동 흐름이 깨질 수 있는 리스크 |
| 일반 버그 | 예상치 못한 오류가 플레이 리듬을 끊을 수 있는 리스크 |
| 가격 / 과금 불만 | 가격 대비 만족도가 갈려 구매 타이밍을 따져봐야 하는 포인트 |
| DLC / 확장팩 언급 | 추가 콘텐츠 가치가 확실할 때 만족도가 높아지는 포인트 |
| 반복 / 목적성 부족 | 중후반 반복감이 커지면 동기 유지가 떨어질 수 있는 리스크 |
| 매칭 / 서버 문제 | 매칭 대기나 서버 상태에 따라 체감 품질이 흔들릴 수 있는 리스크 |
| 밸런스 불만 | 특정 구간 불공정 체감이 누적되면 피로도가 높아질 수 있는 리스크 |
| 번역 / 현지화 품질 | 한국어 품질에 따라 몰입과 진입장벽이 크게 달라지는 포인트 |
| 건축 조작 불편 | 배치/건설 인터랙션이 익숙해지기 전 불편할 수 있는 구간 |
| 콘텐츠 부족 | 플레이 시간이 누적될수록 새로움이 빨리 소진될 수 있는 리스크 |
| 세이브 / 진행 유실 | 진행 데이터 안정성이 만족도를 크게 좌우하는 리스크 |
